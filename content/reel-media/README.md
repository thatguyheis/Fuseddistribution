# Reusable reel and blog media

Follow `docs/REEL-ENRICHMENT-SOP.md` for selection and review.

Local generated assets: `video/local/generated-backgrounds/catalog.json` and its `assets/` directory. Reuse the raw source PNG for a new crop when available; review the new crop. Illustration is not documentary evidence.

Stock assets: `video/local/stock-media/catalog.json` and `assets/`. Entries retain provider, creator, original source, license link and hash. Only `approved-supporting-imagery` entries are eligible for automatic reuse. Do not publish this internal library as downloadable stock.

Original coin evidence: `content/coin-library/catalog.json`. Respect withdrawn or unverified attributions. The earlier Morgan example is not evidence of an O mint mark.

These media libraries live within this project on disk. Large runtime assets may be Git ignored; no remote backup or Git publication is implied. Preserve them with the project's media backup.

Initial reviewed example: `content/reel-media/enrichment-pilot.json`, containing one locally generated recording-room illustration (plus its raw PNG), one stock video and one stock photo. The visual-only preview is `.workflow-state/reel-enrichment-2026-10-13/preview.mp4`.
