# Client reel instructions

Before starting a new reel, fetch Fused's current reel instructions using the installed `fetch-instructions.mjs` loader. Read its output for this run. If it exits with an error, stop the reel workflow and report the HTTP status or connection failure. Do not use a saved copy from an earlier run.

Keep completed videos, drafts, approvals, and your own brand information in this repository. Keep the Fused access token in your local secret store, outside Git. This file is a bootstrap pointer, not the paid instruction bundle.
