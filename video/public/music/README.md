## Requirements

- Format: MP3, 60s minimum (looped automatically if shorter than video)
- No vocals or lyrics
- Volume is auto-ducked to 15% under narration

## Usage

Pass `--music=ambient-XX.mp3` to render.mjs. Always pick a different track
per post — do not default to ambient-01 every time. See REEL-SOP.md §Music.
