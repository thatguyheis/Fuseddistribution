# Reel Script: what-is-an-sop-and-why-ai-needs-one
format: long-form

---

## HOOK
**Duration:** 4s minimum
Narration: Why does AI keep forgetting your process?

---

## OVERLAY: An SOP is the repeatable method
Narration: A standard operating procedure, or SOP, is the current written method for doing a recurring task. It names the goal, the allowed inputs, each step, the output, the checks, and what to do when something is missing. It stays useful after one chat ends.

---

## OVERLAY: A prompt is not the whole process
Narration: A prompt asks for work now. The SOP describes how that work should happen every time. Your prompt can point to the SOP, then add the details for this request. That means you do not have to rebuild the same background and rules at every handoff.

---

## OVERLAY: One rulebook for every tool
Narration: One AI can draft, another can check facts, and a person can approve. Give them one canonical source of truth for privacy, format, evidence, and stopping rules. Without it, each tool can fill missing context differently or quietly skip a review.

---

## OVERLAY: Pass the same context
Narration: At each handoff, name the SOP version, completed step, verified facts, unresolved questions, next action, and output location. Never assume the next AI can see another chat or folder. Confirm it can access the instructions before it starts.

---

## OVERLAY: Make review and stop rules clear
Narration: Tell the AI what it may draft, what a person must approve, and when to stop. Missing facts, conflicting sources, private data, or a failed connection should trigger a pause and a clear note, not a guess or a duplicate.

---

## OVERLAY: Improve one canonical copy
Narration: Date the SOP and name its owner. When a real run reveals a missing step, update the canonical copy and remove outdated instructions from the workflow. Test the change on a small example, then let every tool use that same current version.

---

## OVERLAY: Start with one repeatable task
Narration: Choose a process you repeat each week. Write the input, steps, checks, destination, and stopping point. Ask another person to follow it without extra coaching. Add only the directions they actually need.
