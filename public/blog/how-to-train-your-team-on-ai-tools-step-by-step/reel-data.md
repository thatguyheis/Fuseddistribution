## segments
- type: overlay
 text: DEFINE ONE ACCEPTABLE RESULT
 narration: Choose one repeatable job your team already understands, such as drafting an estimate response from approved notes. Define what an acceptable draft contains and what it must not promise. Name who approves the source and who reviews the result. Sending a response or confirming an appointment is a separate action from writing the draft.
- type: overlay
 text: PREPARE A PRACTICE PACKET
 narration: Use fictional customer details, approved facts and a written expected outcome. Include an incomplete request so trainees practise identifying missing information. Check that everyone can find the source and save their work. If the instructions are unclear, repair them before using the exercise to assess a person or compare performance.
- type: overlay
 text: SHOW THE REVIEW PROCESS
 narration: Demonstrate the source, instruction, generated answer and review together. Include an imperfect answer and show exactly what needs correction. A polished final example hides that work. Compare every business claim with the supplied notes, and save the original output alongside the corrected draft so the changes can be inspected afterward.
- type: overlay
 text: ASSESS A NEW CASE
 narration: Let each person complete a new fictional request independently. Check whether the draft answers the actual question, preserves the approved facts and avoids invented commitments. Record missing details and unresolved questions. Attendance alone does not establish proficiency; the useful evidence is a reviewed result and a clear understanding of when to ask for help.
- type: overlay
 text: COUNT ALL THE WORK
 narration: In a hypothetical example, the original task takes ten minutes. The assisted task takes two minutes to prepare and generate, four to review and correct, and one to save. That totals seven minutes, saving three. Do not report eight minutes saved by ignoring review and saving. This example is not a measured business result.
- type: overlay
 text: KEEP THE METHOD CURRENT
 narration: Save the approved source, reusable instruction, review conditions and escalation contact with a version date. When a policy or tool changes, update the practice packet and repeat the affected exercise. Keep failed examples as well as successes, then expand to another task only when the reviewed work supports that decision.
