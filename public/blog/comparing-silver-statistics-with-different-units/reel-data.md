# Compare Silver Statistics With Different Units

hook: Before the chart, check the units.

## segments
- type: overlay
 text: CHECK THE SCALE BEFORE CONVERTING
 narration: A heading can express values in individual units, thousands or another stated scale. Copy that wording into the worksheet. An apparent difference may come from the scale of presentation rather than the underlying measure. Do not assume that a chart copied from another source preserved the original heading. Keep the original value unchanged in one column and put any converted value in another. Record the conversion rule and its source.
- type: overlay
 text: CONFIRM THAT THE QUANTITIES MATCH
 narration: Matching units does not establish that two figures measure the same thing. Check the reporting period, geography, material category and whether the figure refers to contained silver. A valid mass conversion cannot turn two different statistical concepts into equivalent measures. Our guide to reading a USGS summary explains preserving table context. Use the same discipline for estimates and footnotes.
- type: overlay
 text: MAKE ROUNDING VISIBLE
 narration: Retain enough detail in your working calculation to reproduce it, then choose an appropriate presentation precision. Avoid adding decimal places that suggest more certainty than the original estimate supports. Label a rounded display so it is not mistaken for the exact working value. When explaining the result, distinguish source data from your calculation.
- type: overlay
 text: REVIEW THE COMPARISON BEFORE SHARING IT
 narration: Ask another reader to trace one displayed result back to the original value, unit and conversion. They should be able to identify the edition and reporting period without guessing. If that path is unclear, improve the worksheet before publishing a chart. A useful final note names the two measures, explains the conversion and states any remaining limitation.

## question
When a chart looks surprising, do you check its units or its source first?
