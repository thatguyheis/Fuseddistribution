# Label the storage, not the coin

hook: Label the storage, not the coin

## segments
- type: overlay
 text: ASSIGN AN ID
 narration: Give each coin or group a unique code, such as S-001. Put the code in your inventory and on a separate card or the outside of the storage box. For a group of coins, assign each coin its own ID and record which compartment contains it. Keep the code descriptive enough to distinguish similar items, but leave sensitive details such as safe combinations out of the label.
- type: overlay
 text: LABEL THE STORAGE
 narration: Do not attach a sticker to the coin. Keep labels, adhesive, ink, and other marking materials away from the coin and its holder. Put a paper tag in a box index, attach it to the outside of a larger storage container, or use a divider card beside the holder. For a certified coin, record the certification number in your inventory and label the storage position instead of covering the holder's printed label or security features.
- type: overlay
 text: MATCH THE RECORD
 narration: Keep one inventory row for each ID. Useful fields include the ID, a plain description, the holder or certification number when present, the box and compartment, and the date you last checked the record. A spreadsheet is enough for a small collection. If you use a QR code, print it on a separate card or the outside of the container and link it to the same inventory record; treat the code as a shortcut, not as proof of authenticity or ownership.
- type: overlay
 text: CHECK LOCATIONS
 narration: Color can help distinguish boxes or broad groups, but do not make it the only identifier. Pair every color with a written ID so the system still works if a tag fades, a box moves, or someone else needs to read the inventory. Use removable dividers or cards that do not contact the coin itself.
