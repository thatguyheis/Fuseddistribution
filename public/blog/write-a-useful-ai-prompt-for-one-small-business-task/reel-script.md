# Reel Script: write-a-useful-ai-prompt-for-one-small-business-task
format: long-form

---
## HOOK
**Duration:** 4s
Narration: What should an AI prompt say?

---
## OVERLAY: Pick one repeatable task
**Duration:** 20s
Narration: Start with work you already understand, so you can judge whether the answer is useful. Choose a bounded example, such as turning public event notes into one caption. Skip a sweeping request like “run my business.” Decide who will read the caption, what they need to know, and which details must stay accurate.

---
## OVERLAY: Give safe context
**Duration:** 20s
Narration: Tell the model the audience, purpose, and approved facts. If the task depends on a document, include only the relevant passage. For practice, use a fictional event rather than customer records. Name the source that controls if two details disagree, and ask the model to list missing information instead of filling gaps.

---
## OVERLAY: State the limits
**Duration:** 20s
Narration: Set boundaries that protect the result. Say what to include, what to leave out, and what the model must not invent. For the event caption, you might forbid an unconfirmed price, address, deadline, or registration link. Clear limits make the output easier to check, but they do not prove that its claims are true.

---
## OVERLAY: Name the output
**Duration:** 20s
Narration: Describe the shape of the answer you need. Ask for one caption under a chosen word count, a short checklist, or a table with named columns. State the tone in plain words, such as friendly and direct. Add a length limit only when the next step has a real space constraint.

---
## OVERLAY: Check and refine
**Duration:** 20s
Narration: Compare the draft with the source and your goal. Verify names, dates, and claims before use. If it is too long, refine the length instruction; if it missed context, supply the source. Change one part at a time. Save the useful prompt with its approved input and review steps in your SOP.
