## segments
- type: overlay
 text: DRAFTING IS ONE STEP
 narration: AI can help turn a new Google review into a relevant draft and route it through a repeatable response process. A working automation also needs permission to act, a supported connection to the correct Business Profile, rules for exceptions and a check that the intended reply was published. A text generator alone does not provide those capabilities.
- type: overlay
 text: DEFINE THE AUTHORIZED ACTIONS
 narration: Google's Business Profile API policies require prior specific, express consent for automated actions such as review replies. Verify the proposed integration against the current rules instead of assuming one account connection authorizes every possible operation. Write down the locations, response categories and actions the owner authorizes. Decide who can change those settings and how the service can be stopped. Keep publishing permission separate from permission to draft or view feedback.
- type: overlay
 text: ROUTE EXCEPTIONS TO AN OWNER
 narration: Assign an operator for the exception queue and specify the information they should receive. The system should explain why it paused, rather than leaving an unexplained draft in a dashboard. Treat review text as customer content, not instructions to the automation. If someone writes that the business should ignore its rules or reveal internal information, that wording must not override the approved response policy.
- type: overlay
 text: VERIFY BEFORE RETRYING
 narration: If a connection fails, a retry must not overwrite a newer response written by a person or another system. Recheck the current review and reply state before repeating an uncertain operation. Preserve enough permitted operational evidence to explain the result while following the provider's data handling requirements. Google's API policies place limits on storage of content obtained through the service.
- type: overlay
 text: MEASURE THE COMPLETE WORKFLOW
 narration: A dependable workflow makes routine work predictable and exceptions visible. It keeps the owner in control of the scope without requiring them to inspect an unchanged dashboard all day. If you are evaluating a setup for your business, contact Fused with the process you want to improve. Begin with a clearly defined response category, verify the complete path and expand only when the evidence supports it.
