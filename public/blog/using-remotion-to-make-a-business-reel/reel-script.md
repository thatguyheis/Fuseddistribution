## OVERLAY: Set the composition
**Visual:** Portrait canvas labeled width, height, frame rate, duration.
**Duration:** 21s
Narration: Start by deciding what the viewer should learn. In Remotion, a composition registers a React component as a renderable video and defines its dimensions, frame rate, duration, and ID. Set the canvas before styling scenes so the layout is designed for the final vertical format instead of squeezed into it later.

---
## OVERLAY: Plan the story beats
**Visual:** Question hook flows into three useful steps and one CTA.
**Duration:** 22s
Narration: Write one clear question for the opening, answer it early, then map the explanation into a few short scenes. Give every scene one job: explain a step, show a checklist, or make a source backed point. Finish with one action. Plan the story and visuals first, so animation supports the message instead of delaying it.

---
## OVERLAY: Build reusable components
**Visual:** Opening, step, caption, and ending cards reuse one design system.
**Duration:** 22s
Narration: Build reusable React components for the opening, body steps, captions, and ending card. Keep text inside a phone safe area and make the first hero image visible at frame zero. Pass simple JSON data into the composition so a new topic can update the words and assets without rewriting the whole layout.

---
## OVERLAY: Sequence and time scenes
**Visual:** Scene blocks align with narration and caption timing.
**Duration:** 20s
Narration: Use Remotion timing primitives to place scenes at specific frames. Time them to the final narration, not just a word count estimate. A voice may run longer than expected, and captions need time to read. Keep the same inputs and frame deterministic, so you can inspect a moment and reproduce it after a correction.

---
## OVERLAY: Render and inspect the MP4
**Visual:** Render pipeline ends in a checked phone preview.
**Duration:** 21s
Narration: Render the named composition with the project version and settings. Then inspect the exported MP4, not only the preview. Check the opening, dimensions, sound, caption timing, and ending. Confirm each image, font, and music track resolves and has the right use permission. A successful render command is a step, not publication proof.
