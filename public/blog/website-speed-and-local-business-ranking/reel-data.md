## segments
- type: overlay
 text: START WITH A CUSTOMER TASK
 narration: Choose a home page, a service page, and the place where someone contacts or books. Try the same actions on a phone. Record the device, connection, and date. Watch for delayed content, slow responses, and buttons that move while you tap.
- type: overlay
 text: READ THE REPORT IN CONTEXT
 narration: Separate a controlled lab test from field data collected from real users. Check whether the field report describes the page or the whole origin. Missing data is unavailable evidence, not a pass or failure. Use diagnostics to choose the next investigation.
- type: overlay
 text: FIX THE CRITICAL IMAGE
 narration: Find the image or other element identified as Largest Contentful Paint. Check its dimensions, quality, discovery, and loading priority. Do not lazy load that critical image. Smaller bytes alone do not solve late discovery or a delay before rendering.
- type: overlay
 text: TEST ONE SCRIPT CHANGE
 narration: List the widgets and integrations on the page. Identify the customer function each one serves. In a controlled preview, change one candidate at a time and test the original action again. A faster score is not success if the booking form breaks.
- type: overlay
 text: CHECK CACHING AND HOSTING
 narration: Match caching rules to the resource. Public images and personalized account pages need different treatment. Check how updates become visible. Investigate an initial response delay before buying hosting. Record the expected benefit and the evidence that would confirm or reject it.
- type: overlay
 text: VERIFY THE CUSTOMER JOURNEY
 narration: Repeat the original tests under comparable conditions. Check navigation, forms, appointments, and confirmation messages. Keep a dated record of the change and result. Good performance measurements do not guarantee search placement or a particular increase in sales.
