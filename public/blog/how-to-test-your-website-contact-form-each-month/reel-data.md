## segments
- type: overlay
 text: CHOOSE A CONTACT FORM TEST OWNER
 narration: List every form that accepts an inquiry, including contact pages, quote requests, and campaign pages. Assign someone to perform the test and someone to receive it. Use a test address you control, a harmless sample message, and a unique reference so the team can identify it.
- type: overlay
 text: SUBMIT FROM A CUSTOMER VIEW
 narration: Open the live page on a phone and a desktop browser. Read each label, enter valid information, and submit once. Record the page address and time. Check whether the confirmation explains what happened and what to expect next, without promising a response time the business cannot meet.
- type: overlay
 text: TEST ERRORS WITHOUT LOSING THE MESSAGE
 narration: Try an empty required field and an incorrectly formatted email address. Check that the error identifies the field and explains how to correct it. Use the keyboard to move through the form. Confirm that correcting an error does not erase a message the customer already typed.
- type: overlay
 text: CONFIRM CONTACT FORM DELIVERY
 narration: Find the test message in the intended inbox or lead system. Compare its reference, sender address, service selection, and message with what you submitted. Check spam and quarantine if it is absent. A website success screen alone does not establish that notification delivery worked.
- type: overlay
 text: REPLY AND INSPECT THE DESTINATION
 narration: Reply from the mailbox your team normally uses, then confirm the reply arrives at your test address. Pay attention to the reply destination: a form can notify staff correctly but still point replies at a system address. Record any missing fields that would prevent useful follow up.
- type: overlay
 text: RETEST AFTER THE REPAIR
 narration: If a test fails, keep the reference and identify the failed stage before changing settings. Retest the same path after the repair and save the result. Repeat after changes to forms, email routing, spam protection, or the website platform, rather than waiting for the next monthly check.
