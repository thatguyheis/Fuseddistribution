# Why Coin Edges Have Different Designs

hook: The third side has a design.

## segments
- type: overlay
 text: DISTINGUISH THE COIN EDGE FROM THE RIM
 narration: The edge is the outside surface between the two faces. The rim is the raised border around a face. The Mint's anatomy guide distinguishes these terms and explains that the rim helps protect the design from wear. Using the right term makes a photograph or a question much easier for someone else to interpret.
- type: overlay
 text: COMPARE DIFFERENT COIN EDGE DESIGNS
 narration: A plain edge lacks the repeated grooves associated with a reeded edge. A lettered edge carries lettering, while decorated edges use other design details. These categories provide a starting vocabulary. For an actual attribution, preserve the issuer's wording rather than forcing every unfamiliar pattern into the closest familiar category. Build a comparison using documented examples you already own or can inspect through reliable images.
- type: overlay
 text: CHECK THE SPECIFICATION FOR THE PARTICULAR ISSUE
 narration: Write down the issuer, denomination, year and product version before comparing the edge. A general article about a denomination may not describe the exact item in front of you. Find an issuer record for that version where possible, and save the link with the description you used. If the record does not answer your question, keep the field unresolved.
- type: overlay
 text: RECORD AN UNUSUAL COIN EDGE WITHOUT OVERCLAIMING
 narration: Describe what is visible before suggesting a cause. For example, a collector's note might say that a short section looks smoother than the neighboring grooves. That is an observation. Calling it a mint error introduces a separate conclusion that needs suitable evidence. Preserve the original image so a later assessment can revisit the same detail.
