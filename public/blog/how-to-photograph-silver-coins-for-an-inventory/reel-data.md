# Photograph Silver Coins for a Useful Inventory

hook: Photograph Silver Coins for a Useful Inventory

## segments
- type: overlay
 text: PREPARE THE CAMERA
 narration: Prepare a stable surface and suitable lighting, then check the camera framing with the holder in place. Move unrelated coins and private paperwork out of the picture. If glare prevents a clear view, change the lighting or camera position before adding another handling step. Record that an area remains obscured if you cannot show it clearly. Do not remove protection just to make an image appear more polished.
- type: overlay
 text: CAPTURE IDENTIFICATION
 narration: Take a record view that connects the item with its inventory ID, followed by separate views of the sides when practical. Keep the label beside the holder or in a separate reference frame instead of attaching it to the coin. Check each image before moving on to another item. A blurred photograph named correctly is still a weak record, so confirm that the detail you intended to capture is actually visible.
- type: overlay
 text: SAVE ORIGINAL FILES
 narration: Use a consistent filename that contains the inventory ID and a view description. Keep the capture date with the record and retain the original files separately from versions prepared for sharing. Avoid overwriting the only original when cropping or resizing. If several coins look similar, compare the holder information with the inventory before saving the images into a folder. Correct a mismatch before it spreads into later records.
- type: overlay
 text: DESCRIBE THE VIEW
 narration: Write a short note explaining what the photograph shows and any limit on the view. For example, distinguish a visible mark from a reflection you could not resolve. Do not infer when a feature appeared solely from a new photograph taken under different lighting. When comparison matters, keep the setup as consistent as practical and preserve both images rather than replacing the older one with a cleaner looking version.
