# Record what you can see

hook: Record what you can see

## segments
- type: overlay
 text: IDENTIFY THE COIN
 narration: Give each coin a unique inventory ID and use it consistently on the record and on the outside of its storage box or compartment. Note the date, coin type, date and mint mark when legible, denomination, and any holder or certification number. If a detail is uncertain, mark it as uncertain rather than guessing. Keep private information such as the exact location of a home safe out of any shared or public copy. Back up the inventory separately from the physical collection.
- type: overlay
 text: DESCRIBE OBSERVATIONS
 narration: Use neutral observations instead of a grade. For example, note whether design details appear sharp or worn, whether you see spots, scratches, discoloration, or contact marks, and where those features appear. Describe only what is visible under consistent lighting; do not infer how or when a mark occurred. A coin's grade is a professional assessment of condition. PCGS explains that grading assesses a coin's physical condition, including its wear and marks. A written inventory note is useful for tracking, but it is not a grade or an authentication.
- type: overlay
 text: KEEP ORIGINAL PHOTOS
 narration: If you photograph coins, capture the obverse and reverse with the coin centered and the lighting and distance kept as consistent as practical. Include the inventory ID in a separate frame or label beside the holder, not attached to the coin. Keep original files and dates so later images can be compared with the same coin.
- type: overlay
 text: RECORD CHANGES
 narration: Add the holder type and the box or compartment location. When you move a coin, update the location and date rather than changing the original observation. If a new mark or spot appears, record what changed and when you noticed it; avoid claiming a cause unless you know it.
