# Review Image Alt Text on Service Pages

hook: Review Image Alt Text on Service Pages

## segments
- type: overlay
 text: LIST IMAGE PURPOSES
 narration: List the images on one service page and note whether each one is informative, functional, decorative, or more complex than a short description can explain. Include icons used as controls and images inside cards. Save a screenshot or file reference to identify each item. Do not assume the same photograph needs identical wording everywhere if it serves a different purpose in another part of the website.
- type: overlay
 text: READ NEARBY CONTENT
 narration: Read the current alternative beside the heading, caption, and surrounding paragraph. Ask whether it adds the information the image contributes or simply repeats words that are already present. Keep descriptions factual and specific to the actual image. Do not insert an unobserved location, customer identity, or service outcome to make the wording sound more persuasive. Unsupported detail is still unsupported when it appears in alt text.
- type: overlay
 text: CHECK IMAGE CONTROLS
 narration: For an image that activates a link or button, review what the control does as well as what the picture shows. Ask the developer to check the accessible name in the complete control, including any adjacent text. A visible icon alone may not communicate the intended action clearly. Record the expected destination or action in your issue so the wording and technical implementation can be assessed together.
- type: overlay
 text: CHOOSE ALTERNATIVES
 narration: Use the W3C image decision guidance with your developer when deciding how an image should be represented. Do not fill every decorative asset with an unnecessary description merely to make a checker appear complete. For a diagram with important relationships or data, identify where the fuller explanation will live. A short label cannot carry an entire process when the surrounding page supplies no equivalent information.
