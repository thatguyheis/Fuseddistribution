## HOOK

**Visual:** Count finished work. Include the fixes.
**Duration:** 22s minimum

Narration: An automation can produce many drafts while leaving the team with more work. Count a task as complete only when it meets the same acceptance criteria used for manual work. Then measure the effort required to reach that point, including review, corrections and any follow up caused by mistakes. Choose one bounded workflow for the first comparison.

---

## OVERLAY: RECORD THE MANUAL BASELINE

**Visual:** Record the manual baseline
**Duration:** 28s minimum

Narration: Take a small, authorized set of representative cases and record how they are currently completed. Separate hands on work from waiting time. Note difficult cases rather than removing them because they make the average look worse. Keep confidential customer information out of the measurement sheet. Our guide to choosing a first AI task can help establish the boundary. Compare like with like: a checked, ready draft should not be compared with an unchecked generated answer.

---

## OVERLAY: COUNT REVIEW AND CORRECTION EFFORT

**Visual:** Count review and correction effort
**Duration:** 26s minimum

Narration: For each trial case, record initial preparation time, review time, correction time and whether the result passed. Add a short error category, such as missing fact, wrong policy or unclear instruction. Avoid vague scores that cannot explain what the reviewer actually had to repair. Record rejected outputs as part of the trial. A tool that produces a usable answer only after several attempts has consumed effort on those attempts too.

---

## OVERLAY: CHECK QUALITY BEFORE COMPARING SPEED

**Visual:** Check quality before comparing speed
**Duration:** 24s minimum

Narration: Use the same acceptance criteria for both approaches. A faster process that silently drops important checks is a different process, and its speed does not establish an improvement. The support draft test set guide explains defining expected outcomes for difficult inputs. Look at failures individually as well as at totals. One serious incorrect action may matter more than several small wording corrections.

---

## OVERLAY: DECIDE WHAT TO CHANGE NEXT

**Visual:** Decide what to change next
**Duration:** 24s minimum

Narration: Summarize completed cases, failed cases, total effort and the most common correction. Treat a small trial as evidence about those cases, not proof of universal savings. If results vary sharply, identify which case types need a different approach or must stay with a person. Choose one next change, such as clearer input requirements or a narrower task boundary, and repeat the same comparison.
