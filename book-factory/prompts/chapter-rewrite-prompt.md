# Chapter Rewrite Prompt

Write each chapter as a standalone manuscript draft in the house style:

- Keep the lesson intact.
- Use a modern setting with grounded economic details.
- Prefer builders, operators, freelancers, creators, and tech-adjacent professionals as characters.
- Open with tension, move into the lesson, then end on a memorable takeaway.
- Avoid mimicry of the source text.
- Avoid claiming the original author wrote this version.

Outputs should read like publishable draft prose, not outlines.
