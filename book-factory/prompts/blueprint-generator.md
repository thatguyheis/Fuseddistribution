# Adaptation Blueprint Prompt

Generate an adaptation blueprint that preserves the original lesson structure while changing the narrative world for modern builders.

Required sections:

- Core promise of the original work
- Audience lens
- Modern metaphor or setting
- Tone rules
- Source-aligned cast map
- Core lesson map
- Chapter transformation plan
- Prohibited changes
- Editorial risks

The blueprint must preserve the lesson sequence, simplify jargon, and use concrete examples from business building, freelancing, sales, investing, software, or digital work.

## Source-Aligned Cast Map Requirements

For narrative adaptations, include a cast map with:

- The original source character name
- The adapted character name
- A one-sentence rationale for how the new name preserves the source lineage while fitting the modern setting

Naming rules:

- Keep names close to the original source name's sound, rhythm, or recognizable root when practical.
- Create parody through fictionalized archetypes, roles, status signals, and modern context, not through direct use of famous living people's names.
- Avoid names that are direct references to real public figures, brands, founders, celebrities, or trademarked companies.
- If using a high-profile cultural archetype, make the character a clearly fictional composite and keep the source-name lineage more prominent than the celebrity echo.
